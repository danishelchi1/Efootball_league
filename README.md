# ⚽ Efootball League

**A private 12-player round-robin football league manager.**

🔗 **Live Site:** https://danishelchi1.github.io/Efootball_league/

## Features
- 📊 Auto-updating league table (Points → GD → GF → H2H)
- 📅 All 11 rounds of fixtures (circle-method scheduling)
- 🏆 Stats: top scorers, win streaks, biggest victory, clean sheets
- 👥 Player profiles with form, win%, match history
- 🔐 Admin PIN protection — only admin can enter/edit scores
- 🌙 Dark/Light mode
- 💾 LocalStorage — data persists across sessions
- 📤 Export to JSON / CSV / PDF
- 🎊 Confetti when the league winner is confirmed
